
# INFR3120 Assignment 2 - Personal Portfolio

## About My Portfolio

For my INFR3120 Assignment 2, I created a personal portfolio website using Node.js, Express.js, and EJS.

The purpose of this website is to introduce myself, share some of the projects I've worked on throughout my time at Ontario Tech University, and provide a way for people to connect with me.

I also used Bootstrap to help with the website's layout and Font Awesome to add icons throughout the pages.

## Pages

My portfolio has four main pages:

**Home:** A short introduction about myself and my portfolio.
**About Me:** More information about my education, my technical skills, work experiences, and future goals.
**Projects:** All three projects I've worked on involving networking, cloud infrastructure, and web development.
**Contact Me:** Links to my GitHub and LinkedIn profiles.

## Technologies Used

- Node.js - Allows JavaScript to run on the server.
- Express.js - Handles the website's routes and page requests.
- EJS - Allows me to create website pages using templates and shared sections.
- Bootstrap - Helps with the website's layout, navigation bar, and styling.
- Font Awesome - Provides the icons used throughout the website.
- HTML - Structures the content displayed on each page.
- CSS - Controls the appearance and styling of the website.
- JavaScript - Used with Node.js and Express.js to run the website.

## How to Run My Website

1. Download or clone this repository from GitHub.
2. Open the project folder in Visual Studio Code.
3. Open the terminal and run npm install to install the required packages.
4. Run npm start to start the website.
5. Open http://localhost:3000 in your browser to view the portfolio.
